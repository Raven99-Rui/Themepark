# 紙間照相館 · The Paper Photobooth

一個不需要後端、沒有外部依賴的復古紙藝拍照亭。掀開簾子、投入硬幣、四連拍，最後從機身外側的取相口吐出一張黑白銀鹽四格相紙，寫上名字、日期與留言，保存為 PNG。

## 線上版

**https://raven99-rui.github.io/Themepark/**

GitHub Pages 目前從 `gh-pages` 分支發佈；更新網站內容時，請同步更新 `main` 與 `gh-pages`，或把 Pages Source 改為 `main`。

## 快速預覽

在專案資料夾內啟動任何靜態伺服器即可。最簡單的方法：

```powershell
# Windows PowerShell
python -m http.server 8765 --bind 127.0.0.1
```

然後打開 <http://127.0.0.1:8765/>。

也可以直接雙擊 `serve.cmd`（需要安裝 Python 3）。

> 即時相機需要安全來源（HTTPS 或 localhost）。如果用手機透過區域網路 IP 開啟 `http://192.168.x.x:8765`，瀏覽器不會提供即時鏡頭；此時可改用「系統相機」逐格拍攝，或把整個資料夾放到任何支援 HTTPS 的靜態託管（GitHub Pages、Netlify、Vercel、Cloudflare Pages 等）。

## 使用流程

1. **掀簾進場** — 直接點擊／拉開簾子；手機亦可按頁面下方「掀開簾子」。布簾收合後會自動進入拍照亭。
2. **投幣** — 點金色硬幣，聽到硬幣落入的聲音。
3. **四連拍** — 每張 3 秒倒數，自動開啟鏡頭補光與螢幕閃光。共四張。
4. **沖印** — 四格完成後進入暗房顯影，相紙由機身外側的 PRINT SLOT 吐出。
5. **取相與簽名** — 取回相紙，輸入名字、日期與 28 字內留言。即時預覽，最後只匯出 PNG。

沒有鏡頭時，可以：

- **使用系統相機**：每格開啟手機原生相機拍攝（iOS / Android / 微信均可用）。
- **試玩紙偶**：用內建的紙藝人像完成一次完整試拍，不需要任何相機權限。

## 相機打不開時

- 確認網址是 `http://localhost`、`http://127.0.0.1` 或 `https://`。直接雙擊 `index.html`（`file://`）時，瀏覽器會封鎖即時相機。
- 如果頁面出現在嵌入預覽框（例如檔案預覽卡片）中，頁面會顯示「在新分頁開啟」按鈕；請在新分頁操作。
- 若網址列左側的相機／鎖頭圖示顯示「已封鎖」，請改為允許相機並重新載入。
- 確認 Windows「設定 → 隱私權與安全性 → 相機」允許桌面應用程式使用相機，並關閉其他佔用鏡頭的程式（Zoom、Teams、OBS 等）。
- 電腦版的使用者按下「開啟相機」後，若在畫面轉場的一瞬間按下，程式會等轉場完成再開啟鏡頭，不需要連按。

## 相容性

- 桌面 Chrome / Edge / Safari / Firefox。
- iPhone Safari、iPad Safari、Android Chrome。
- 微信內建瀏覽器：
  - 部分版本的微信 WebView 不提供 `getUserMedia`，會自動顯示「系統相機」後備方案。
  - 微信不支援 `<a download>`，保存 PNG 時會打開長按儲存面板；長按相紙儲存到相簿。
- 所有影像只在瀏覽器本機以 Canvas 處理，不上傳。

## 技術

- 純 HTML / CSS / JavaScript，無框架、無 CDN、無需 build。
- 拍照亭以手寫 SVG 繪製，簾子可拖曳或以按鈕打開，打開後自動進場。
- 相片效果：灰階、銀鹽 S 曲線、微粒、暗角、塵點與輕微高光暈染。
- 音效全部以 Web Audio API 即時合成：快門、倒數、硬幣、簾子、沖印馬達、提示鐘聲。
- PNG 以 Canvas 合成：四格照片、片頭字樣、日期、名字與留言，720 × 2516 px。
- 手機、平板、桌面的響應式排版，並支援 `prefers-reduced-motion`。

```
├─ preview-landing.png # 桌面版拍照亭外觀

├─ preview-strip.png   # 720 × 2516 PNG 相紙範例
└─ README.md
```

## 測試用參數

在網址加上 `?fast=1` 可以把倒數與沖印動畫加速，方便自動化測試；一般不應使用。

```
http://127.0.0.1:8765/?fast=1
```

## 操作提示

- 右上角可隨時開關音效。
- 即時相機頁的「切換鏡頭」只會在裝置有多個鏡頭時出現。
- 若手機屏幕較小，拍照亭頁面可上下捲動；主要按鈕均為適合觸控的尺寸。
- 想修改名字、日期或留言，完成後回到相紙頁即可即時更新；按「再影一輯」會保留硬幣與名字，讓你快速再拍一次。
